A working notebook of the SQL and database questions that actually come up in data scientist interviews. Every level has hands-on query drills and theory questions. Cover the answer, write it yourself, then check.

🌱 Easy ⚡ Medium 🔥 Hard 🧮 SQL drills 📘 Theory 🎨 10 themes … questions

How to use this notebook. Work top-to-bottom. For SQL drills, read the question, hide the answer, and type the query out in a scratch editor (or on paper) before revealing. For theory questions, say the answer out loud in 30–60 seconds — that's exactly the format of a phone screen. Tick Mastered only when you can answer without peeking. Your progress is saved in this browser.

SQL dialects differ: LIMIT is PostgreSQL/MySQL, TOP is SQL Server, FETCH FIRST n ROWS ONLY is Oracle. DATE_TRUNC, PERCENTILE_CONT, and INTERVAL arithmetic are shown in PostgreSQL syntax — always mention the dialect you're assuming in an interview.
